# Global Superstore Sales Analytics Dashboard

## 1. Project Title / Headline

### Global Superstore Sales Analytics Dashboard

An interactive Power BI dashboard designed to analyze sales, profit, market performance, product categories, and delivery trends using the Global Superstore 2016 dataset.

---

## 2. Short Description / Purpose

This project focuses on converting raw sales data into meaningful business insights using Power BI.

The dashboard provides an overview of sales and profit performance and allows users to explore trends across different markets, product categories, years, and shipping modes.

The main goal is to make sales data easier to understand through interactive visualizations and KPIs.

---

## 3. Tech Stack / Technologies Used

* Power BI – Dashboard creation and data visualization
* DAX – Creating calculated measures and KPIs
* KPI Cards – Displaying key business metrics
* Charts – Analyzing sales, profit, and trends
* Slicers & Filters – Interactive data analysis

---

## 4. Data Source

### Global Superstore 2016 Dataset

Source: Kaggle

The Global Superstore 2016 dataset contains sales-related information including orders, customers, products, categories, markets, sales, profit, quantity, shipping modes, and delivery details.

This dataset was used to perform sales and profitability analysis and create the Power BI dashboard.

---

## 5. Features / Highlights

* Total Sales: 12.64M
* Total Profit: 1,467.5K
* Average Delivery Days: 3.97
* Sales analysis across Asia Pacific, Europe, USCA, LATAM, and Africa
* Profit analysis by Technology, Office Supplies, and Furniture
* Monthly sales trend analysis
* Year filter: 2012–2016
* Ship Mode filter
* Interactive KPI cards and charts
* DAX-based calculations and measures
* Interactive dashboard for exploring sales and business performance
